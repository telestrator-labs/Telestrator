# Product & Design

The *why / for-whom / how-it-should-feel* of Telestrator — the product-and-design counterpart to the
engineering plan in [../greenfield-build-guide.md](../greenfield-build-guide.md) and
[../stack-decisions.md](../stack-decisions.md). Written post-**M5**, once the core idea (a reactive
notebook) is real and worth shaping into a product.

**In one line:** Telestrator is a **reactive notebook for explorable explanations** — documents where
prose and live TypeScript/React cells share state, so the explanation and the thing it explains are the
same artifact. Primary audience: **explorable authors & educators** (and their readers).

## How this relates to the build guide
The [build guide](../greenfield-build-guide.md) sequences **capability** (M0–M8); these docs sequence
**craft and fit**. They interleave: the near-term authoring increment + design-language styling pass
slot alongside M6 (collaboration) and M7 (sharing), so the product gets *better to use*, not just *more
capable*. When in doubt, apply the one-line test: *does it help someone turn an idea into a shareable,
interactive explanation?*
