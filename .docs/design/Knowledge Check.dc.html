Telestrator · new cell type
Knowledge check — authoring node
A reactive check cell: the author writes a question and marks the answer; a passed check writes a $ key (like an input cell) so prose and downstream cells can react to whether the reader got it. Three directions below — each pairs the authoring face with a live reader preview. Supports multiple choice, multi-select, true/false, short text, numeric-with-tolerance, and predict-a-$-value.
